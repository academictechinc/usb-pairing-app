How to re-pair a set ›
  1. Isolate. Unplug every other Logitech receiver nearby — you want only one active during the test.
  2. Power down. Switch off the keyboard and mouse (or pull a battery briefly).
  3. Plug in the receiver you're working on.
  4. Find the connect button — a small recessed button on the receiver itself (may need a pin), or on the underside of the keyboard/mouse. Location varies by model.
  5. Press and hold the connect button for 2–3 seconds.
  6. Power the device on within ~20 seconds of pressing connect (repeat for keyboard and mouse separately — most models pair them independently).
  7. Test it — type a key and nudge the mouse. If both respond, it's paired.
Button placement differs across MK270 / MK320 / MK345-style sets. If a set won't re-pair after two tries, note the model below — it may be a true fixed-pair unit with no re-pair option, and matching it to its original receiver by trial is the fallback.
